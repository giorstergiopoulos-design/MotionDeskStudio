Βιβλιοθήκες τρίτων

Η εφαρμογή περιλαμβάνει επίσης τις παρακάτω βιβλιοθήκες ανοιχτού κώδικα, η καθεμία υπό τη δική της
άδεια:

- LibreHardwareMonitorLib (github.com/LibreHardwareMonitor/LibreHardwareMonitor)
  Mozilla Public License 2.0. Χρησιμοποιείται για την ανάγνωση πραγματικών sensors φόρτου/
  θερμοκρασίας/τάσης της GPU στο widget System Monitor. Πλήρες κείμενο άδειας: mozilla.org/MPL/2.0

- NAudio / NAudio.Wasapi (github.com/naudio/NAudio)
  Άδεια MIT. Χρησιμοποιείται για WASAPI loopback capture και FFT στο widget Audio Visualizer.

- Microsoft.Web.WebView2 (Microsoft Edge WebView2 SDK)
  Χρησιμοποιείται για την απόδοση των φόντων βίντεο στο Wallpaper Studio.

- .NET / Windows Forms runtime
  Άδεια MIT, (c) .NET Foundation and contributors.
