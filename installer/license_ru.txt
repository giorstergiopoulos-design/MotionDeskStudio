Сторонние компоненты

Это приложение также включает следующие библиотеки с открытым исходным кодом, каждая под собственной лицензией (описания — в английском тексте):

- LibreHardwareMonitorLib (github.com/LibreHardwareMonitor/LibreHardwareMonitor)
- NAudio / NAudio.Wasapi (github.com/naudio/NAudio)
- Microsoft.Web.WebView2 (Microsoft Edge WebView2 SDK)
- .NET / Windows Forms runtime

----------------------------------------------------------------------

Данные о погоде загружаются во время работы из бесплатного API Open-Meteo (open-meteo.com), а в качестве резерва — из wttr.in (github.com/chubin/wttr.in); оба сервиса используются без ключа API, и никакие личные данные, кроме запрошенных координат/названия города, не отправляются.
