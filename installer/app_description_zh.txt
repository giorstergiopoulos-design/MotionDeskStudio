MotionDesk Studio

适用于 Windows 10/11 的免费开源桌面自定义与工作区外壳——动态壁纸、悬浮桌面小组件、区域吸附窗口布局以及
安全的系统图标个性化，全部集成在一个轻量应用中。

主要功能：

* 壁纸工作室 - 在桌面图标后方渲染的动态视频/GIF 壁纸（WorkerW 注入），在游戏或其他应用全屏时自动暂停，
  并提供感知电池的性能模式（高 / 平衡 / 低功耗 / 电池）。

* 小组件库 - 原生且支持主题的桌面小组件：时钟（数字/模拟，12/24 小时制）、系统监视器
  （CPU/内存/网络/GPU）、网络吞吐量、由真实系统音频驱动的音频可视化（WMP Legacy / Winamp 风格）、
  天气（温度、风力/蒲福风级、湿度、动态天气图标）以及磁盘使用情况。每个小组件都可以锁定位置，并在
  会话之间记住其位置。

* DeskZones 与 DeskContainers - FancyZones 风格的窗口吸附到自定义区域布局，以及 Stardock Fences 风格的
  容器，用于在桌面上对文件/文件夹/快捷方式分组，支持拖放。

* 个性化（IconAtlas）- 仅通过 Windows 官方注册表机制更改“此电脑”和回收站（空/满）图标以及各文件夹图标，
  不修补任何系统文件。

* 工作区配置文件、自动化规则、命令面板、托盘集成和全局热键使整个外壳更加完整。

应用完全在本地运行；唯一的网络访问是在天气小组件处于活动状态时，从免费的 Open-Meteo/wttr.in API
获取天气数据。
