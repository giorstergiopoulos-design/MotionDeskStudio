- NAudio / NAudio.Wasapi (github.com/naudio/NAudio)
- Microsoft.Web.WebView2 (Microsoft Edge WebView2 SDK)
- .NET / Windows Forms runtime

----------------------------------------------------------------------

天気データは、実行時に無料の Open-Meteo API (open-meteo.com)、フォールバックとして wttr.in (github.com/chubin/wttr.in) から取得されます。どちらも API キー不要で、要求された座標/都市名以外の個人データは送信されません。
