MotionDesk Studio

Windows 10/11용 무료 오픈 소스 바탕 화면 사용자 지정 및 작업 영역 셸입니다. 라이브 애니메이션 배경 화면,
떠 있는 바탕 화면 위젯, 영역 맞춤 창 레이아웃, 안전한 시스템 아이콘 개인 설정을 가벼운 앱 하나에
담았습니다.

주요 기능:

* 배경 화면 스튜디오 - 바탕 화면 아이콘 뒤에 렌더링되는 애니메이션 동영상/GIF 배경 화면(WorkerW 삽입),
  게임이나 다른 앱이 전체 화면이 되면 자동 일시 중지, 배터리 인식 성능 모드(높음 / 균형 / 절전 / 배터리).

* 위젯 갤러리 - 테마가 적용된 기본 바탕 화면 위젯: 시계(디지털/아날로그, 12시간/24시간), 시스템 모니터
  (CPU/RAM/네트워크/GPU), 네트워크 처리량, 실제 시스템 오디오로 구동되는 오디오 시각화(WMP Legacy /
  Winamp 스타일), 날씨(온도, 바람/보퍼트, 습도, 애니메이션 날씨 아이콘), 디스크 사용량. 각 위젯은 위치를
  잠글 수 있으며 세션 간에 위치를 기억합니다.

* DeskZones 및 DeskContainers - 사용자 지정 영역 레이아웃에 맞추는 FancyZones 스타일 창 맞춤, 그리고
  바탕 화면의 파일/폴더/바로 가기를 묶는 Stardock Fences 스타일 컨테이너(끌어서 놓기 지원).

* 개인 설정(IconAtlas) - 공식 Windows 레지스트리 방식만 사용하여 "내 PC"와 휴지통(비어 있음/가득 참)
  아이콘, 폴더별 아이콘을 변경합니다. 시스템 파일은 수정하지 않습니다.

* 작업 영역 프로필, 자동화 규칙, 명령 팔레트, 트레이 통합, 전역 단축키가 셸을 완성합니다.

앱은 전적으로 로컬에서 실행되며, 네트워크 접근은 날씨 위젯이 활성화되었을 때 무료 Open-Meteo/wttr.in
API에서 날씨 데이터를 가져오는 경우뿐입니다.
