MotionDesk Studio

Бесплатная оболочка с открытым исходным кодом для настройки рабочего стола и рабочего пространства в
Windows 10/11: живые анимированные обои, плавающие виджеты рабочего стола, раскладки окон с привязкой к
зонам и безопасная персонализация системных значков — всё в одном лёгком приложении.

Основные возможности:

* Студия обоев - анимированные видео/GIF-обои за значками рабочего стола (внедрение в WorkerW),
  автоматическая пауза, когда игра или другое приложение переходит в полноэкранный режим, и режимы
  производительности с учётом батареи (Высокая / Сбалансированная / Энергосбережение / Батарея).

* Галерея виджетов - нативные виджеты рабочего стола с поддержкой тем: Часы (цифровые/аналоговые,
  12/24 ч), Монитор системы (ЦП/ОЗУ/сеть/ГП), пропускная способность сети, аудиовизуализатор (стили
  WMP Legacy / Winamp) на основе реального звука системы, Погода (температура, ветер/Бофорт, влажность,
  анимированный значок) и использование дисков. Каждый виджет можно закрепить, и он запоминает своё
  положение между сеансами.

* DeskZones и DeskContainers - привязка окон в стиле FancyZones к пользовательским раскладкам зон, а также
  контейнеры в стиле Stardock Fences для группировки файлов/папок/ярлыков на рабочем столе с поддержкой
  перетаскивания.

* Персонализация (IconAtlas) - изменение значков «Этот компьютер» и «Корзины» (пустой/полной) и значков
  отдельных папок только официальными механизмами реестра Windows — без правки системных файлов.

* Профили рабочего пространства, правила автоматизации, палитра команд, интеграция с треем и глобальные
  горячие клавиши завершают оболочку.

Приложение работает полностью локально; единственный доступ к сети — загрузка данных о погоде из
бесплатных API Open-Meteo/wttr.in, когда активен виджет погоды.
