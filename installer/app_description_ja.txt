MotionDesk Studio

Windows 10/11 向けの無料のオープンソース デスクトップ カスタマイズ & ワークスペース シェルです。ライブ
アニメーション壁紙、フローティング デスクトップ ウィジェット、ゾーンにスナップするウィンドウ レイアウト、
安全なシステム アイコンの個人用設定を、軽量なアプリ 1 つにまとめました。

主な機能:

* 壁紙スタジオ - デスクトップ アイコンの背後に描画されるアニメーション動画/GIF 壁紙 (WorkerW 組み込み)、
  ゲームや他のアプリが全画面になったときの自動一時停止、バッテリー対応のパフォーマンス モード
  (高 / バランス / 低電力 / バッテリー)。

* ウィジェット ギャラリー - テーマ対応のネイティブ デスクトップ ウィジェット: 時計 (デジタル/アナログ、
  12 時間/24 時間)、システム モニター (CPU/RAM/ネットワーク/GPU)、ネットワーク スループット、実際の
  システム オーディオで動くオーディオ ビジュアライザー (WMP Legacy / Winamp スタイル)、天気 (気温、
  風/ビューフォート、湿度、アニメーションの天気アイコン)、ディスク使用量。各ウィジェットは位置を固定でき、
  セッション間で位置を記憶します。

* DeskZones & DeskContainers - カスタム ゾーン レイアウトに合わせる FancyZones 風のウィンドウ スナップと、
  デスクトップ上のファイル/フォルダー/ショートカットをまとめる Stardock Fences 風のコンテナー
  (ドラッグ アンド ドロップ対応)。

* 個人用設定 (IconAtlas) - Windows 公式のレジストリの仕組みだけを使って、「PC」とごみ箱 (空/いっぱい) の
  アイコンやフォルダーごとのアイコンを変更します。システム ファイルは書き換えません。

* ワークスペース プロファイル、自動化ルール、コマンド パレット、トレイ統合、グローバル ホットキーが
  シェルを仕上げます。

アプリは完全にローカルで動作します。ネットワークへのアクセスは、天気ウィジェットが有効なときに無料の
Open-Meteo/wttr.in API から天気データを取得する場合のみです。
