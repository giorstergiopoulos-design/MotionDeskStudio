MotionDesk Studio

Ένα δωρεάν, ανοιχτού κώδικα κέλυφος εξατομίκευσης επιφάνειας εργασίας για Windows 10/11 - ζωντανά
κινούμενα φόντα, αιωρούμενα widgets επιφάνειας εργασίας, διατάξεις παραθύρων με κούμπωμα σε ζώνες,
και ασφαλής εξατομίκευση εικονιδίων συστήματος, όλα σε μία ελαφριά εφαρμογή.

Βασικές λειτουργίες:

* Wallpaper Studio - κινούμενα φόντα βίντεο/GIF που αποδίδονται πίσω από τα εικονίδια της επιφάνειας
  εργασίας (μέσω WorkerW injection), αυτόματη παύση όταν τρέχει παιχνίδι ή άλλη εφαρμογή σε πλήρη
  οθόνη, και λειτουργίες απόδοσης ανάλογα με την μπαταρία (Υψηλή / Ισορροπημένη / Χαμηλή κατανάλωση /
  Μπαταρία).

* Widget Gallery - θεματισμένα, εγγενή widgets επιφάνειας εργασίας: Ρολόι (ψηφιακό/αναλογικό, 12/24
  ώρες), System Monitor (CPU/RAM/δίκτυο/GPU), ταχύτητα δικτύου, Audio Visualizer (στυλ WMP Legacy /
  Winamp) με πραγματικό ήχο συστήματος, Καιρός (θερμοκρασία, άνεμος/Μποφόρ, υγρασία, κινούμενο
  εικονίδιο ανάλογα με τη συνθήκη), και χρήση δίσκων. Κάθε widget μπορεί να κλειδωθεί στη θέση του
  και θυμάται τη θέση του ανάμεσα σε sessions.

* DeskZones & DeskContainers - κούμπωμα παραθύρων σε προσαρμοσμένες διατάξεις ζωνών (στυλ
  FancyZones), και containers στο πνεύμα του Stardock Fences για ομαδοποίηση αρχείων/φακέλων/
  συντομεύσεων στην επιφάνεια εργασίας, με υποστήριξη drag-and-drop.

* Εξατομίκευση (IconAtlas) - αλλαγή εικονιδίου "Ο Υπολογιστής μου" και Κάδου Ανακύκλωσης (άδειος/
  γεμάτος), καθώς και ανά-φάκελο εικονίδια, μέσω επίσημων μηχανισμών του registry των Windows - καμία
  τροποποίηση αρχείων συστήματος.

* Προφίλ Εργασίας, κανόνες Αυτοματισμού, Command Palette, ενσωμάτωση στο tray, και global
  συντομεύσεις πληκτρολογίου συμπληρώνουν το κέλυφος.

Η εφαρμογή τρέχει εξ ολοκλήρου τοπικά· η μόνη πρόσβαση στο διαδίκτυο είναι για δεδομένα καιρού από
τα δωρεάν API Open-Meteo/wttr.in όταν είναι ενεργό ένα widget Καιρού.
