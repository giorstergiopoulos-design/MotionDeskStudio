타사 구성 요소

이 앱에는 다음 오픈 소스 라이브러리도 포함되어 있으며 각각 고유한 라이선스를 따릅니다(설명은 영어 텍스트 참조):

- LibreHardwareMonitorLib (github.com/LibreHardwareMonitor/LibreHardwareMonitor)
- NAudio / NAudio.Wasapi (github.com/naudio/NAudio)
- Microsoft.Web.WebView2 (Microsoft Edge WebView2 SDK)
- .NET / Windows Forms runtime

----------------------------------------------------------------------

날씨 데이터는 실행 중에 무료 Open-Meteo API(open-meteo.com)에서, 대체로 wttr.in(github.com/chubin/wttr.in)에서 가져옵니다. 둘 다 API 키가 필요 없으며, 요청한 좌표/도시 이름 외의 개인 데이터는 전송되지 않습니다.
